# currency_converter_mobile

Мобильный конвертер валют для Android на **Flutter (Dart)** по официальному курсу
Национального банка Молдовы (НБМ). Лабораторная работа №4.

## Возможности

- **Конвертер.** Пересчёт между любыми валютами НБМ и молдавским леем при вводе суммы,
  обмен валют местами, курс пары, дата курса и источник.
- **Неделя и месяц.** График курса выбранной пары за 7 и 30 дней, минимум и максимум с датами,
  среднее, изменение в единицах и процентах, тенденция (рост / падение / без изменений).
- **Офлайн.** Последний курс и все загруженные дни хранятся на устройстве и переживают
  перезапуск. Без сети показываются сохранённые данные с датой их актуальности.
- **Ошибки источника** (нет сети, таймаут, пустой ответ, HTML вместо XML, битые записи)
  не роняют приложение: пользователь видит понятное сообщение.

## Требования

- Flutter 3.47+ (Dart 3.13+), Android SDK, эмулятор или телефон с Android

## Запуск

```
flutter pub get
flutter run
```

## Тесты

Все unit-тесты запускаются одной командой из корня проекта:

```
flutter test
```

| Файл | Что проверяет |
|---|---|
| `test/bnm_parser_test.dart` | разбор XML НБМ, номинал, запятая в числах, пустой день, битый XML, HTML вместо XML |
| `test/period_stats_test.dart` | минимум, максимум, среднее, изменение и %, тенденция, пустой набор данных |
| `test/amount_input_test.dart` | валидация суммы: пусто, ноль, минус, буквы, `nan`, слишком большая сумма |
| `test/rate_sheet_test.dart` | конвертация в обе стороны, кросс-курс через MDL, номинал, формат чисел |
| `test/rate_repository_test.dart` | выходные, нет сети, кэш после перезапуска, история за неделю/месяц офлайн |

Сеть в тестах не используется: источник подменяется заглушкой.

## Источник данных

`https://www.bnm.md/ru/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`. Курс за каждый
день истории запрашивается отдельно (до 6 запросов параллельно) и кэшируется навсегда.

## Структура

```
lib/
├── main.dart
└── src/
    ├── app.dart, app_state.dart          # навигация и общее состояние

    └── ui/                               # экраны и виджеты (график — CustomPainter)
test/                                     # unit-тесты
```
